# 决策：产品名「四野」的对外 ASCII 标识 —— 拼音 vs 英文意译

- 日期：2026-09-15
- 状态：**已实施（产品语义层）；仓库名暂缓**
- 相关：`docs/features/tray-launcher.md`

## 背景

产品中文名是**四野**，但工程名仍是 fork 遗留的 `MediaCrawler`。两者并存造成了真实困惑：
`README.md` 首屏不得不专门澄清「本项目的产品主体是跨平台搜索，而不是通用爬虫控制台」——
**一个需要澄清的名字本身就是持续成本**。

同时名字在三个层次上不统一：

| 层 | 改名前的写法 | 例子 |
|---|---|---|
| 产品展示层 | 四野（中文） | UI 标题、落地页 `<title>` / `og:title`、release notes |
| 技术标识层 | siye（拼音小写） | `assets/siye-icon.png`、`SIYE_PORT`、`siye-landing-theme`、托盘 icon id |
| 工程遗留层 | MediaCrawler（英文） | 仓库名、Pages 路径、后端 EXE、zip 包名 |

问题：对外需要一个 ASCII 名时，是造一个英文意译名，还是直接用拼音？

## 关键事实（决定了选项空间）

- **意译没有好选项，且全部误导。** 四野 → FourWilds（像户外品牌）/ FourFields（像农业公司）/
  FourRealms（像游戏）。而且产品是搜小红书 / 抖音 / B站 / 知乎的，任何英文意译都解释不了它做什么。
- **拼音已经是既成事实。** 图标文件名、环境变量、localStorage 键、托盘图标 id，
  四个不同时期写下的标识全是 `siye`，没有一处是意译。
- **没有需要英文名的使用场景。** 本地运行、Windows 桌面端、只服务国内平台、落地页全中文。
  给中文用户看的产品配英文意译名，收益为零，代价是每次都要解释「为什么叫这个」。
- **仓库改名有外链代价。** `kellengo.github.io/MediaCrawler/` 已经写进落地页的 `canonical`、
  `og:url`、README 和 release notes，v0.2 也已发布。GitHub 会给旧 Pages 链接做 301，
  但已分享的链接和搜索收录要重新攒。

## 选项

| | 做法 | 收益 | 代价 |
|---|---|---|---|
| **A** | ASCII 用拼音 `SiYe`，只摘产品语义，仓库名不动 | 消除对外误导；零外链风险 | 仓库名与产品名仍不一致 |
| B | 拼音 `SiYe` + 连仓库名一起改 | 彻底统一 | 打断已外发的 Pages / release 链接 |
| C | 造一个英文意译名 | 理论上「更像产品名」 | 无好选项，且引入新的解释成本 |

## 决定

采用 **A**：

- **产品展示层**：继续用**四野**，不引入任何英文名。
- **技术标识层**：继续用 `siye`，不动。
- **工程遗留层**：统一 ASCII 标识为 **`SiYe`** —— 后端 EXE `MediaCrawler.exe` → `SiYe.exe`
  （同步 `tray_main.py` 的 `MAIN_EXE_NAME` 与 `scripts/package_exe.py` 的校验清单）；
  落地页 `alternateName` 改为 `SiYe`；README 首屏把「四野（SiYe）」前置。

**写法约定：写 `SiYe` 不写 `Siye`。** 连写会被英语读者读成 /saɪ/（像 sigh），
首字母大写拆成两个音节可读。中文场景一律「四野」，`SiYe` 只出现在需要 ASCII 的地方。

## 后果 / 待办

- 这轮**故意没动**的三处，理由是它们属于「发布通道」而非「产品身份」，改动会打断已生效的链接：
  - GitHub 仓库名与 Pages 路径（`kellengo.github.io/MediaCrawler/`）；
  - zip 包名 `MediaCrawler-Windows-x64.zip`（落地页 `releases/latest/download/` 依赖 asset 名）；
  - `dist/MediaCrawler/` 目录名（`MediaCrawler.bat` 与文档都引用它）。
- 落地页 `keywords` **同时保留** `MediaCrawler` 并新增 `SiYe`：旧名是搜索兜底，不是产品身份。
- 等下次大版本或正式推广前，再把仓库名、Pages、zip 名、dist 目录名**一次性**改掉，
  届时同步 git remote、Pages 设置与所有外链。
- 改名后 `docs/features/tray-launcher.md` 里的 PE subsystem 校验（`SiYe.exe=3` Console）需跟着走。

## 被否掉 / 暂缓的方案及原因

- **英文意译名（C）**：无好选项，且会引入比 `MediaCrawler` 更难解释的新名字。
- **这轮就连仓库名一起改（B）**：收益真实（省掉 README 那句澄清），
  但 v0.2 刚发布、外链刚生效，收益不配这个打断；留到大版本一并做。
