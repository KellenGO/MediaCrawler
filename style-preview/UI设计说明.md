# 四野 聚合搜索 · UI 设计说明（交接文档）

> 本文档用于把当前确定的设计方向交接给另一个 agent / 开发者。
> 它记录了"定下来的样子"、"实测的设计数值"、"明确否决的做法"，以及落地到真实工程要注意什么。
> 参考实现（可直接打开看）：`style-preview/8-startpage.html`

---

## 1. 项目与工程现状

**这是什么**：一个 Windows 本机运行的"中文社交平台聚合搜索"工具。输入一个关键词，同时搜小红书 / 抖音 / B站 / 知乎，结果统一去重合并展示。

**技术栈**：
- 前端：React 18.3 + Vite 6 + TypeScript 5.6 + Tailwind CSS 3.4.17
- 组件基座：Radix UI primitives（目前只用了 `@radix-ui/react-select`、`react-slot`）+ 手写的 shadcn 风格组件（cva + tailwind-merge）
- 其他：zustand（主题）、TanStack Query、sonner（toast）、**lucide-react（图标，已有依赖）**
- 后端：Python FastAPI，服务在 `http://127.0.0.1:8080`，前端产物由后端托管

**关键约束（会影响设计决策）**：
1. **离线**：应用打包成 exe 分发，跑在系统默认浏览器里。所以**不能依赖 CDN 字体/图标**。
   现状问题：`webui/index.html` 现在从 `fonts.googleapis.com` 取 Inter / JetBrains Mono，断网会掉字体，必须改自托管。
2. **Tailwind 是 3.4**：daisyUI 5、最新 shadcn 主题、tweakcn 等一批方案都要求 Tailwind 4，用不了（除非先升级）。
3. **结果列表可能很长**（几十上百条），是性能敏感区。

**现有设计令牌体系**（这是好消息，换皮成本低）：
- `webui/src/index.css` 里定义了两套变量：
  - `--brand` / `--ok` / `--warn` / `--danger` / `--cyber-*`：**RGB 通道三元组**（如 `--brand: 76 164 220`），被 Tailwind 以 `rgb(var(--x) / <alpha-value>)` 消费
  - `--background` / `--foreground` 等 shadcn 语义色：**HSL 三元组**
- 暗色：`.dark` 类挂在 `<html>` 上，由 zustand store（`webui/src/store/themeStore.ts`，localStorage key `mediacrawler_theme`）切换
- 现有组件里 `cyber-*` / `brand-*` 工具类共约 **243 处，分布在 17 个 tsx 文件**
- 页面：聚合搜索页、账号设置页、跨平台收藏页

## 2. 最终确定的设计方向

**一句话：学 startpage.com 的首页 —— 纯白、极简、一个强调色只用一次、靠留白和发丝细线分层。**

要求：**"洁白简单，不要花哨。"**

### 2.1 首屏

- 居中「四野」字标（深藏青，56px / 700 / letter-spacing -1.6px）
- 字标下方一条**靛蓝→青绿渐变下划线**（这是从 Startpage 学来的signature元素）
- 字标下方**一个搜索框**，没有别的
- **没有标语**（曾有"一次搜索，同时看小红书、抖音、B站和知乎"，已按要求删除）

### 2.2 右上角：纯文字入口，无底色无边框

| 元素 | 说明 |
|---|---|
| `● 登录状态 3/4` | 前面一个 7px 绿点（`#12a67a`），点击去账号设置 |
| `跨平台收藏` | 纯文字链接 |
| `账号设置` | 纯文字链接 |
| `自定义` | 打开自定义弹层（见 2.4） |
| 主题切换图标 | 太阳/月亮，纯图标按钮 |

所有条目默认态是**灰色文字、无背景、无边框**，hover 只变品牌色。

### 2.3 两种模式（都要保留，用户明确要求）

| 模式 | 内容 |
|---|---|
| **极简** | 只有字标 + 搜索框，内容区垂直居中 |
| **实用**（默认） | 首屏之后追加卡片区；首屏改为靠上（`padding-top:15vh`） |

**实用模式的卡片区**（排列学 UP云搜，外观仍是 Startpage 那套洁白细线）：

```
┌──────────────────────┬──────────────┐
│ 热门搜索（标签）      │ 历史搜索      │
├──────────────────────┼──────────────┤
│ 热门资源（结果列表）  │ 最新结果      │
└──────────────────────┴──────────────┘
```
- 两列网格：`grid-template-columns: 1.45fr 1fr`（左宽右窄），`gap: 18px`
- 容器 `max-width: 920px`，**与搜索框同宽、左右边缘对齐**
- 卡片：白底 + **1px 发丝细线** + 16px 圆角，**没有阴影、没有彩色填充**
- 卡片标题：12.5px / 600 / letter-spacing .06em / 灰色，前面一个 6px 渐变小圆点，右侧一个次要操作（换一批 / 清空 / 按互动排序 / 按时间排序）

### 2.4 自定义（可配置是明确需求）

右上角「自定义」打开一个小弹层（白底 + 1px 细线 + 16px 圆角 + 柔和阴影）：
- **首页模式**：`极简` / `实用` 两个分段按钮，选中态 = 品牌色描边 + 品牌色文字
- **下方显示哪些板块**：4 个勾选框 —— 热门搜索 / 历史搜索 / 热门资源 / 最新结果（`accent-color: var(--brand)`）
- 选择**持久化在 localStorage**（key 建议 `siye-home-prefs`）
- 交互细节：在极简模式下勾选任一板块 → 自动切到实用模式
- 关闭方式：点击外部 / Esc

### 2.5 各组件的做法（照这个来，别自己发挥）

| 组件 | 做法 |
|---|---|
| **搜索框** | 宽 920px（与内容区对齐）、高 60px、**纯白底 + 1px `#6573FF` 描边 + 全圆角（999px）+ 零阴影**；左侧 20px 灰色放大镜；右侧 44px 品牌色圆形发送按钮；聚焦时外圈 `0 0 0 4px var(--brand-soft)` |
| **关键词（热门搜索）** | **纯文字链接**，无底色无边框无圆角；14.5px、行间距 `9px 20px`；hover 变品牌色加下划线；"热门"的几个加粗 + 末尾一个 5px 渐变小圆点 |
| **结果列表** | 发丝细线分隔的行；`序号 + 标题 + （小圆点 + 平台名 · 作者 · 时间）+ 右对齐数字`；**不用缩略图、不用卡片**；hover 标题变品牌色 |
| **平台标识** | 只用 **6px 彩色圆点**（小红书 `#ff4d6d`、抖音 `#202945`、B站 `#ff5c8a`、知乎 `#0f88eb`） |
| **页脚** | 一排 12.5px 小灰字链接，居中 |
| **图标** | 全部用**手写内联 SVG**，`stroke-width: 1.75`，`stroke-linecap/linejoin: round`，`fill: none`。**严禁 emoji。** 真实工程里直接用已有的 `lucide-react` |
| **圆角** | 卡片/弹层 16px、输入框与按钮全圆角、小按钮 9–10px |
| **阴影** | 基本不用。只有弹层允许一个柔和大阴影 |

## 4. 明确否决的做法（别再犯）

按"被否掉的原因"排序：

1. **❌ 用 emoji 当图标**（🔥🕐👁🌙）—— 每台电脑渲染不一样、颜色杂、一眼业余。全部改手写 SVG / lucide。
2. **❌ 多套颜色互相抢**：曾经主色浅蓝 + 平台标记红/黑/粉/蓝 + 灰色标签 + 背景光斑，共四五套颜色。现在收敛成"一个品牌色 + 一个中性灰阶 + 只有 6px 圆点带平台色"。
3. **❌ 重卡片**：带阴影、带彩色填充的卡片。改成"白底 + 1px 细线 + 无阴影"。
4. **❌ 挤**：卡片内边距、行距、标签间距都放大了一档（卡片 20–22px，列表行 13px 垂直）。
5. **❌ 没有图就没有质感** —— 当时的补救是加缩略图；**最终方案的取舍是"干脆不要缩略图"**，靠排版和留白撑住，因为缩略图会带来彩色块、破坏洁白感。
6. **❌ 照抄 UP云搜的视觉**（紫色 + 彩色标签 + 重卡片）—— 只学它的**卡片排列**，不学它的**外观**（用户原话："不要像 UP云搜一样有点花哨"）。
7. **❌ 一次性做三套风格各一份** —— 结果三套都丑。教训：**先把基础手艺（配色/图标/间距/层次）做对，再谈换风格。**

### 4.1 探索过但**没有采用**的方向（留作备选，别再默认推荐）

| 风格 | 结论 |
|---|---|
| **Material You (M3)** | 配色用官方 `@material/material-color-utilities` 以品牌色 `#4ca4dc` 真实生成，观感不错（大圆角 + 药丸按钮 + 色调分层 + 零模糊）。但**真 M3 涟漪/动效需要 `@material/web`**，它是 Web Components + Shadow DOM，会让现有 243 处 Tailwind 工具类全部失效，且**官方已进入 maintenance mode**。**未采用。** |
| **液态玻璃 Liquid Glass** | 做出了**真折射**（canvas 生成位移贴图 → SVG `feImage` + `feDisplacementMap` → `backdrop-filter: url()`），在 Edge/Chrome 里实测有效（开/关像素差 7%–17%）。但：**只有 Chromium 支持**，Firefox 会"假装认识然后什么都不画"，面板变成透明空洞；且**透镜只适合小尺寸元素**，宽条会鼓成椭圆。**未采用为主风格。** |
| **毛玻璃强化** | 实测发现项目原有的 `.glass-panel` 玻璃感≈0，因为 `--glass-bg` 是 **85% 不透明的白**，把模糊完全盖住了；而且背景纯白时**模糊没有东西可模糊**。修法是把 alpha 降到 0.58 左右 + 加 `saturate()` + 顶部内高光 + 背景加淡色光斑。**未采用**（因为最终方向是纯白极简，不需要玻璃）。 |

> 另有一份液态玻璃的详细调研报告在 `docs/liquid-glass-research.md`（子代理产出，未跟踪）。

## 6. 落到真实工程要做的事（给实现者）

1. **换令牌**：把 `webui/src/index.css` 里的 `--brand` / `--cyber-bg-*` / `--cyber-text-*` / `--cyber-border-*` / `--glass-*` 按上面第 3 节的数值改写。
   ⚠️ 注意变量格式：`--brand` 这类是 **RGB 通道三元组**（由 `rgb(var(--x))` 消费），shadcn 的语义色是 **HSL 三元组**。改写时别弄混格式。
2. **改组件**：约 20 个 tsx、243 处 `cyber-*` / `brand-*` 工具类需要按新语言调整。主要文件（按体量）：
   `AccountsPage.tsx`(888行) / `SearchPage.tsx`(394) / `ResultCard.tsx`(340) / `Header.tsx`(325) / `ResultTabs.tsx`(245) / `SearchBar.tsx`(235) / `PlatformStatus.tsx`(194) / `select.tsx`(157) / `ResultTools.tsx`(140)。
3. **替换图标**：把 emoji 换成 `lucide-react`（**已有依赖，不需要新增**）。
4. **自托管字体**：把 Inter 从 Google Fonts 改成项目内自托管（离线 exe 必须）。
5. **加自定义入口**：`themeStore` 从 `'light'|'dark'|'system'` 扩展成再加一个"首页模式 + 板块开关"，或单独建一个 store，持久化到 localStorage。
6. **性能红线**：结果长列表**不要**用 `backdrop-filter` 或 SVG 滤镜（真模糊只给数量固定、面积小的元素）。
7. **不要顺手引入**：新的组件库（MUI / HeroUI / daisyUI / `@material/web` / Radix Themes）。它们要么是 Shadow DOM 隔离、要么自带第二套主题变量，会与现有 `--cyber-*` + shadcn 双令牌体系打架。
