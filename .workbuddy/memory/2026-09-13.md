## 托盘无窗口启动（#7，同日 21:00）
**新增 `tray_main.py`**：统一入口，靠参数区分角色（`--aggregate-worker` / `--frozen-runtime-smoke` / `--no-browser|--server` → 转交 desktop_main；无参数 → 托盘启动器）。启动器负责：单实例文件锁（`data/launcher.lock`，第二次双击只开页面）→ 若 8080 已有本项目后端则复用 → 否则用 `CREATE_NO_WINDOW` 拉起 `MediaCrawler.exe --no-browser` 并把输出重定向到 `data/logs/backend-<日期>.log` → 等 health 就绪（60s）→ 打开浏览器 → pystray 托盘（菜单：打开四野/打开日志目录/退出四野）→ 退出时 `taskkill /F /T` 结束整个后端进程树。失败时用 MessageBoxW 弹可读提示（无控制台模式 print 无效，启动时把 stdout/stderr 兜到 devnull）。
**关键设计（不能只把 console 改 False）**：worker 子进程由 `sys.executable` 拉起并靠 stdin/stdout 管道通信 → 后端那个 EXE **必须 console=True**。所以打包两个 EXE：`MediaCrawler.exe`(console, 后端+worker) + `四野.exe`(windowed, 托盘启动器，隐藏拉起前者)。spec 里两个 EXE 共用同一份 `tray_main.py` 入口。

- **【低】dismissMigration 永久写标记**，用户点"以后再说"后旧数据失去迁移入口 → 改 sessionStorage（本次会话隐藏，下次打开仍提示）。
- **【低】死代码**：bookmarks.ts 的 9 个 localStorage 函数只剩测试引用 → 精简为 publicResult/常量/Bookmark；删除 resultLibrary.test.ts（逻辑由 libraryApi.test.ts + 后端测试覆盖）。
- **【低】updateNote 把 content_id 放路径参数**，含 `/` 的 ID 会有歧义（未修，当前数据无此情况；同文件其他接口都用 body）。
- 环境事实：`requirements.txt` 与 pyproject 的环境标记引号不一致会让 `test_repo_hygiene.py` 红（统一单引号）；.test-dist 旧编译产物会被 run-compiled-tests 一起跑（删源文件后必须清 .test-dist）。
**回归**：后端 914 passed / 0 failed；前端 tsc -b 通过 + 268 passed（含 parseGroupKey 2 个新测试）。
